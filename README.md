# 🛍️ React DummyJSON Product Explorer

A responsive product explorer built with **React.js, Vite, and the DummyJSON REST API**. Fetches and displays product information, including images, prices, categories, and ratings.

## ✨ Features

* 🔗 DummyJSON REST API integration
* 🛍️ Dynamic product listing
* 🖼️ Product images, prices, and ratings
* ⏳ Loading and error handling
* ⚛️ React Hooks: `useState` and `useEffect`
* 📱 Responsive product grid

## 🛠️ Tech Stack

* React.js
* JavaScript
* Vite
* CSS
* Fetch API
* DummyJSON REST API

## 🚀 Getting Started

```bash
git clone https://github.com/vishnuradhakrishnan595-cloud/react-dummyjson-product-explorer.git
cd react-dummyjson-product-explorer
npm install
npm run dev
```

## 🔌 API

**Endpoint:** https://dummyjson.com/products
